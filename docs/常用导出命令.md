# 常用导出命令

本文档记录当前已配置游戏的常用资源导出命令。运行前先进入仓库根目录：

```powershell
cd D:\misutime\UnrealExporter
```

## NTE

```powershell
just nte
```

```powershell
dotnet run --project UnrealExporter nte-useful-assets
```

- 配置文件：`configs/nte-useful-assets.json`
- 示例配置：`configs/examples/nte-useful-assets.json`
- 输出目录：`output/nte-useful-assets`
- Mapping：`mappings/NevernessToEverness.usmap`
- 默认并发：`12`

## Fortnite

```powershell
just fortnite
```

```powershell
dotnet run --project UnrealExporter fortnite-useful-assets
```

- 配置文件：`configs/fortnite-useful-assets.json`
- 示例配置：`configs/examples/fortnite-useful-assets.json`
- 输出目录：`output/fortnite-useful-assets`
- Mapping：`mappings/FortniteGame.usmap`
- 默认并发：`12`
- 默认会从 FortnitePorting API 自动获取 AES、dynamic AES keys 和 mappings，并启用 Fortnite on-demand chunk 读取。
- Fortnite 40.40 / UE 5.8 需要读取 cooked mesh 里的 mobile MinLOD 字段，本工具已在 Fortnite 模式自动开启，否则 GLB 会表现为全部失败或空模型。

## 备注

- `configs/*.json` 是本机实际运行配置，默认不提交 git。
- `configs/examples/*.json` 是可提交的示例配置，需要时复制到 `configs` 后再运行。
- 当前导出策略优先保证资源精简和 GLB 可识别性，少量有用资源优先于大量噪音资源。
